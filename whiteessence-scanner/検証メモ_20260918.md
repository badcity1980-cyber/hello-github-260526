## 4. 案件条件として注意すべき点

詐欺性の問題ではなく、受注時の実務リスクとして。

1. **報酬レンジの提示がない**
   「制作内容やご経験、ご提案内容を踏まえてご相談」＝先に見積もりを出させる形。

2. **「構成・演出からご提案」は企画料が乗るべき範囲**
   台本・構成が支給された前案件（25,000円）とは性質が違う。
   3機種それぞれに別の見せ方を設計する＝実質3本分の企画。

3. **4K（3840×2160）は工数の分岐点**
   前案件の生成クリップは720p（素材README記載）、納品は1080p。
   4K納品はアップスケール前提になるため、どこまでネイティブ4Kに届くかを先に説明しておくべき。
   「ご相談させてください」と書かれているので、こちらから条件を提示する余地がある。

4. **最大の技術的リスク：製品の正確な再現**
   「形状・色・ロゴ・ボタンが支給写真と異なる表現にならないこと」
   「AIで変化した場合は画像加工・映像編集で修正」
   → image-to-videoは製品細部の保持を保証しない。「生成してから崩れを直す」進め方では修正が際限なく発生する。
   **対策：製品本体は支給写真を切り抜いてそのまま使い、動きはカメラワーク・ライティング・合成で作る。**
   生成AIは背景・光・粒子など製品以外の演出に限定する。
   前案件で「日本語テロップは生成AIに描かせず編集で合成」という線引きをして成功したのと同じ考え方。
   この設計を先に提示することが、そのまま先方の最大の懸念への回答になる。

5. **契約経路の確定が必要**
   前案件はココナラ経由。今回はクラウドワークスで募集中とのことだが、連絡はメールで直接来ている。
   - クラウドワークス経由 → システム利用料が発生するので見積もりに反映する必要がある
     （WorClean案件の実例：36,000円提示 → 契約39,600円、手数料控除後30,888円）
   - 直接契約 → 業務委託契約書＋NDA
   - ココナラ経由で知り合った取引先と、別案件をサイト外で直接契約することの是非も一応論点になる
   → **どの経路で進めるかを先方に確認するのが筋。**

6. **実績非公開が続く**
   前案件も社名非公開、今回も未発表製品でポートフォリオ掲載不可。
   受けられる条件ではあるが、実績として使えない仕事が続く点は認識しておく。
